# Agentic QA

Agentic QA automation system using:

- Python
- LangGraph
- Pydantic
- Playwright
- Playwright MCP
- pytest

## Initial Workflow

Requirement
→ Analyze
→ Retrieve Context
→ Explore UI
→ Design Test
→ Generate Test
→ Execute
→ Analyze Result
